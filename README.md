💻 System Requirements
This project is designed to run exclusively on Apple Silicon architecture. It supports the following chips:
• Apple M-Series: M1, M2, M3, M4, M5, and M6
• Apple A-Series: A18 Pro (MacBook Neo)

🛠️ Setup & Installation
Follow these sequential steps to set up and run the application:
1. Install Xcode: Ensure you have the latest version of Xcode installed on your Mac.
2. Install Metal Extension: Add the Metal Toolchain Extension to your Xcode environment.
3. Create a New Project: Open Xcode and create a new App Project.
4. Import Source Files: Drag and drop all provided project files directly into your Xcode project navigation panel.
   
🚀 Compilation & Execution
Before running the application, make sure to clear any previous build cache:
1. Clean Build Folder: Press Shift + Command + K (or go to Product > Clean Build Folder).
2. Build Project: Press Command + B (or go to Product > Build).
3. Run Application: Press Command + R (or go to Product > Run).
